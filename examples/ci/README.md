# Pipeline examples

Deploy, release upgrade, drift detection and image mirroring pipelines for GitHub Actions (`github/`) and Forgejo
Actions (`forgejo/`). They belong in **your** deployment repository, the private repository that holds
your inventories, together with `compliant-infra.ref`; this repository does not run them.

Setup, runners, variables and secrets: [docs/ci.md](../../docs/ci.md).
